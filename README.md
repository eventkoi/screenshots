# EventKoi screenshots

Public staging area for screenshots of EventKoi's throwaway demo site. WordPress downloads each image into its own media library (eventkoi.com/docs and eventkoi.com/blog), and articles use that copy. Nothing on the live sites links here.

- `docs/<post-id>/` – screenshots for knowledge base articles (pushed by eventkoi/kb-pipeline)
- `blog/<slug>/` – screenshots for blog posts (pushed by the marketing project)

Only demo-site screenshots belong here: no customer data, credentials or anything private.
